
# 🍽️ Restaurant Billing System

## 📌 About Project
Restaurant Billing System is a Java-based console application designed to manage restaurant orders and generate customer bills.

## 🚀 Features
- Display Food Menu
- Add Food Items
- Remove Food Items
- Place Customer Orders
- Calculate Subtotal
- Calculate 5% GST
- Generate Itemized Bill
- Input Validation

## 🛠️ Technologies Used
- Java
- OOP Concepts
- ArrayList
- Scanner

## ▶️ How to Run
1. Download or clone this repository.
2. Open the project in any Java IDE.
3. Compile RestaurantBillingSystem.java.
4. Run the program.
